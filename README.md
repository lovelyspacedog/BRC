**Personal BASHRC Configuration System (BRC)** is a modular, extensible bash configuration system that provides a comprehensive set of utilities, aliases, and plugins for enhancing your shell experience.

> ⚠️ **Status: Deprecated** - This project is no longer maintained. Please migrate to [DOGRC](https://github.com/lovelyspacedog/DOGRC).

## Features

- 🎯 **Modular Architecture** - Organized plugin system with clear separation of concerns
- ⚙️ **Configurable** - JSON-based configuration for easy feature toggling
- 🔌 **Extensible** - Easy to add custom plugins and aliases
- 🛠️ **Rich Utilities** - File operations, navigation, information tools, and more
- 📦 **Self-Contained** - All configuration in one directory (`~/BASHRC`)
- 🔄 **Update-Friendly** - Update system that preserves user customizations
- 📊 **Well-Tested** - Basic testing infrastructure (superseded by DOGRC's comprehensive suite)
- ⚡ **Fast** - Lightweight and efficient

## Installation

### Prerequisites

**Required:**
- `bash` (4.0+)
- `jq` - JSON processor (for configuration parsing)

**Recommended:**
- `nvim` - Text editor (used in multiple plugins)
- `pokemon-colorscripts` - For pokefetch plugin
- `fastfetch` - System information tool
- `yay` - AUR helper (Arch Linux)
- `flatpak` - Application framework

**Optional:**
- `eza` - Enhanced `ls` replacement
- `zoxide` - Smart directory navigation
- `starship` - Prompt customization
- `fortune` - Fortune cookies
- And many more (see installation script for full list)

### Quick Install

1. Clone or download the BRC repository
2. Navigate to the BRC directory
3. Run the installation script:

```bash
bash ___INSTALL.sh
```

The installer will:
- Check for required dependencies
- Backup your existing `~/.bashrc` and `~/.bash_profile`
- Copy BRC to `~/BASHRC`
- Generate user-configurable files
- Verify the installation
- Create a redirect in `~/.bashrc` to source BRC

4. Start a new shell session or run:

```bash
source ~/.bashrc
```

## Configuration

### Settings File

Edit `~/BASHRC/settings.json` to enable/disable features:

```json
{
  "check_for_updates": true,
  "enable_automotd": true,
  "enable_blesh": true,
  "enable_manual": true,
  "enable_shellmommy": true,
  "enable_starship": true,
  "enable_vimkeys": true,
  "enable_wlcopy": true,
  "enable_zoxide": true
}
```

**Settings:**

* `check_for_updates` - When enabled (true), automatically checks for BRC updates during shell startup using `brcupdate --silent`. This provides non-intrusive background update checking - you'll only see output if an update is actually available.

### Customization

**Important**: The main `.bashrc` file will be overwritten on updates. For customizations:

1. **Use `_PREAMBLE.sh`**: Edit `~/BASHRC/_PREAMBLE.sh` for user-specific configurations that won't be overwritten. This file is automatically generated by the installer if it doesn't exist, but is not tracked in git - your customizations will persist across updates.
2. **Use `user-scripts/` directory**: Add your custom scripts to `~/BASHRC/user-scripts/` directory. Any `.sh` files in this directory are automatically sourced by `_PLUGINS.sh`. This directory is created automatically and is a safe place for custom scripts that won't conflict with core functionality.
3. **Edit generated files**: Both `_PLUGINS.sh` and `_ALIASES.sh` are generated from templates in `___INSTALL.sh` if they don't exist. Once generated, your manual edits are preserved across updates unless you delete the files. Edit these files to customize plugin loading order or add custom aliases.
4. **Modify plugins**: Edit individual plugin files in `~/BASHRC/` (note: these will be overwritten on updates)

## Usage

### Getting Help

* `brchelp <function>` - Show manual for a specific function
* `available` - List all available functions and plugins
* `plugins` - List loaded plugins
* `aliases` - List all aliases

### Common Commands

```bash
# Navigation
z <directory>        # Jump to frequently used directory
zi                   # Interactive directory picker
navto                # List available destinations from navto.json
navto X              # Jump to destination by key (case-insensitive)
navto --remove P     # Remove destination by key
navto <Tab>          # Tab completion shows destinations with names (e.g., "P - Pictures")
# Tip: running `navto NEWKEY` offers to add a new destination interactively

# File Operations
analyze <file>       # Analyze file contents
extract <archive>    # Extract any archive format
open <file>          # Open with default app

# Utilities
weather              # Show weather
timer <name> <sec>   # Set a timer
pokefetch            # Show random Pokémon
motd print           # Show message of the day
echo "Hello world" | motd make   # Create/overwrite ~/motd.txt from stdin
brcfortune           # Display fortune with typewriter effect
brcfortune --zero    # Display fortune instantly (no animation)

# System
update               # System update helper
cpuinfo              # CPU information
backup <file>        # Backup a file (same directory)
backup --store <file> # Backup a file to ~/Documents/Backups/
backup -s <file>     # Short form: backup to ~/Documents/Backups/
backdoc <file>       # Backup a file to ~/Documents/Backups/

# BRC Management
brchelp <function>    # Show manual for a function
brcversion           # Show installed BRC version
brcupdate            # Check for available updates
brcupdate --silent   # Check silently (no output if up to date)
brcupdate --ignore-this-version  # Mask current repo version (creates ~/BASHRC/version.mask)
```

## Updating

BRC includes an update system that preserves your customizations:

```bash
cd ~/Code/BRC           # Navigate to repository
bash ___UPDATE.sh       # Run update script
```

Your customizations in:
- `_PREAMBLE.sh`
- `_PLUGINS.sh`
- `_ALIASES.sh`
- `user-scripts/`
- `navto.json`

will be preserved during updates.

> ⚠️ **MIGRATION RECOMMENDATION**: Consider migrating to [DOGRC](https://github.com/lovelyspacedog/DOGRC) for continued development and new features.

## Reverting Changes

If you need to revert to your previous `.bashrc`:

```bash
# List available backups
ls ~/.bashrc.backup/

# Restore a specific backup
cp ~/.bashrc.backup/TIMESTAMP.bashrc ~/.bashrc
source ~/.bashrc
```

The installer creates timestamped backups in `~/.bashrc.backup/` before making any changes.

## Troubleshooting

### Installation Issues

* **Permission denied**: Make sure `___INSTALL.sh` is executable: `chmod +x ___INSTALL.sh`
* **Dependency errors**: Install missing required dependencies (bash, coreutils, etc.)
* **Backup failed**: Check write permissions in your home directory

### Runtime Issues

* **Function not found**: Run `available` to see if the plugin is loaded
* **Starship not working**: Check if starship is installed: `command -v starship`
* **Plugin errors**: Check `~/BASHRC/` directory exists and contains the plugin files

### Getting Help

* Use `brchelp <function>` for function-specific help
* Check `~/BASHRC/` for plugin source files
* Review `settings.json` to ensure features are enabled

> ## Migration to DOGRC
>
> If you're using BRC and want to upgrade to the enhanced DOGRC system:
>
> 1. **Backup your customizations**:
>    - `_PREAMBLE.sh` (environment variables, custom functions)
>    - `_ALIASES.sh` (custom aliases)
>    - `user-scripts/` directory (custom plugins)
>    - `navto.json` (navigation bookmarks)
>
> 2. **Install DOGRC**:
>    ```bash
>    git clone https://github.com/lovelyspacedog/DOGRC.git
>    cd DOGRC
>    bash install/_INSTALL.sh
>    ```
>
> 3. **Migrate your customizations**:
>    - Copy content from BRC's `_PREAMBLE.sh` to DOGRC's `config/preamble.sh`
>    - Copy aliases from BRC's `_ALIASES.sh` to DOGRC's `core/aliases.sh`
>    - Copy custom scripts to DOGRC's `plugins/user-plugins/`
>    - Navigation bookmarks are automatically handled
>
> DOGRC offers significant improvements including better organization, comprehensive testing, and many new features.
